# Network Watchdog using Python

A Python-based network monitoring script that performs:
- OS detection
- ICMP ping monitoring
- DNS resolution using Python socket programming
- Logging of network activity

## Concepts Used
- ICMP
- DNS
- TCP/IP
- Packet Analysis

## Tools Used
- Python
- Linux
- Wireshark
- tcpdump

## Features
- Cross-platform ping support
- DNS resolution
- Timestamped logging
- Network traffic capture and analysis
